=============================================
Toy run configuration and reference runtime
=============================================

This folder demonstrates the full p-values stage end to end on the toy
outputs produced by sampling_script_toy_run.py (../sampling_method_expected_output/):
compute_p_values/ computes the raw p-values, then contingency_table/ and
qqplot/ summarize them. Use it to sanity-check your own setup before
pointing the scripts at full-scale inputs.

Date run : 2026-07-27

2) contingency_table/  (contingency_table.py)
=====================================================
Reads compute_p_values/pvalue_matrix.npy and classifies each SNP by which
of the three p-values (univariate, joint, min-subset Bonferroni) clear
THRESHOLD = 5e-8, then prints a 3x3 count/proportion table.
NOTE: base_dir at the top of the checked-in script is still the
"/path/to/p_values" placeholder — point it at compute_p_values/ (or
wherever pvalue_matrix.npy lives) before running.

Runtime: effectively instant at this toy scale (single pass over a
20,000-row array, no batching or parallelism).

Output (contingency_table_output.txt, terminal output captured verbatim):

3) qqplot/  (qqplot_20k_SNPs.py)
=====================================================
Reads compute_p_values/pvalue_matrix.npy and plots joint and min-subset
-log10(p) against univariate -log10(p) for all 20,000 toy SNPs.
NOTE: same out_dir placeholder issue as contingency_table.py above — point
it at compute_p_values/ before running. The legend label "Joint (all 1010
phenotypes)" is a leftover from the full-scale script; this toy run only
used Np=100 phenotypes, so treat that label as describing the full-scale
pipeline the toy is standing in for, not this specific run.

x-axis is capped at ax.set_xlim(0, 40) (added on top of the original
script) so the dense cluster of low-significance SNPs near the origin is
visible instead of being compressed against the left edge by the handful
of outliers reaching -log10(p) ~ 90.

Runtime: effectively instant at this toy scale (single scatter plot over
20,000 points).

Output: qqplot_allSNPs.pdf (saved here as qqplot_20k_SNPs.pdf)


Scaling notes for a full-scale run
=====================================================
col1/col2/col3 and pvalue_matrix scale with N_snps only (not Np, not Ns),
so they stay modest even at full scale (~9.6M SNPs) compared to Z_matrix.npy
or stat_matrix.dat. Peak RAM for compute_p_values scales with
N_WORKERS * (SNP_BATCH * Np * 8 * 2 + Ns * SNP_BATCH * 4) bytes, so raise
N_WORKERS/SNP_BATCH with care as Np and Ns grow. contingency_table.py and
qqplot_20k_SNPs.py both load the full pvalue_matrix.npy into memory at
once — at full scale (~9.6M SNPs x 3 columns x float64) that's roughly
230 MB, still trivial, so no batching is needed for either at any scale.
